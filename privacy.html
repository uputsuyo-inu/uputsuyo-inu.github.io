Privacy Policy

rclone-backup is used only by its owner to copy the owner's own files to the owner's own Google Drive.

  • It requests only the drive.file scope, so it can access only the files it creates.
  • No data is collected, stored, or shared by the developer. Files go directly from the owner's computer to the owner's Google Drive.
  • Authorization tokens are stored only on the owner's computer.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
